- **Part of Speech:** Adjective [Mathematics/Software]
- **Español:** Idempotente (que produce el mismo resultado si se ejecuta varias veces)
- **Definition:** Denoting an element or operation of a set which leaves unchanged every element on which it operates; an API call that can be made multiple times with the same effect as a single call.
- **Example:** *"HTTP PUT requests are designed to be idempotent to prevent duplicate database transactions during network retries."*
- **Mazo Flashcard:** `#flashcards/c1-thematic`
