# 📥 Quick Capture (Bandeja de Entrada)

> **Regla de oro para evitar fricción:** *Captura primero, organiza después (o nunca).*

### ¿Cómo funciona este Inbox?
1. Cada vez que crees una nota rápida con `Ctrl + N`, se guardará automáticamente aquí.
2. No te preocupes por carpetas, tags, colores o taxonomías mientras estés pensando o escribiendo.
3. Solo suelta tus ideas, snippets, borradores o enlaces.
4. **Una vez por semana (o cuando quieras):**
   - Si la nota ya no te sirve: bórrala sin culpa.
   - Si es un concepto de programación: muévela a `Programming/`.
   - Si es de inglés: muévela a `English/`.
   - Si la necesitas rápido: búscala con `Ctrl + O` o con `Omnisearch` (`Ctrl + Shift + F`). ¡Obsidian la encontrará sin importar en qué carpeta esté!
